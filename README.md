# Power BI Sales Performance Dashboard

## Project Overview
An interactive sales dashboard created using Microsoft Power BI to analyze sales and profit across different products and regions.

## Tools Used
- Microsoft Power BI Desktop
- Data Visualization
- Data Analysis

## Dashboard Features
- Total Sales KPI
- Total Profit KPI
- Sales by Product chart
- Sales by Region chart
- Profit by Product chart
- Interactive Region Slicer

## Key Learnings
- Creating KPI cards and charts
- Using slicers to filter data
- Formatting and arranging dashboard visuals
- Analyzing sales and profit data

## How to View
Download `Sales_Performance_Dashboard.pbix` from this repository and open it using Microsoft Power BI Desktop.

## Note
This is a beginner-level portfolio project created for learning and practice.
